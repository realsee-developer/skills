# v2.3.0 — PanoToVR

## 简体中文

- 新增 **PanoToVR**（`panotovr`），将本地全景图生成为如视 VR 空间并获取访问链接。支持自动生成或提供 manifest，以及用已有 task code 继续查询。
- 收录运行时、锁定依赖、双语指南、合成 manifest 模板、脱敏 API 契约、入口索引和生成的 Claude 插件。
- 同时提供 **Argus**、**PanoToVR** 和 **Blender 重建**。专用 Codex 安装器与 `argus.zip` 仍仅包含 Argus。

安装 PanoToVR 到 Codex：

```sh
npx skills add realsee-developer/skills@v2.3.0 --skill panotovr --agent codex
```

PanoToVR 需要 Node.js 22+、npm 10+、对应区域的应用凭据、全景图生成 VR API 权限和明确的上传授权。按 SKILL.md 在安装后的 skill 目录安装运行依赖。

验证范围为仓库契约、分发同步、全新安装烟测、运行时语法与帮助命令和发布门禁。不宣称新增远程处理或实际 Blender 重建验证。Argus 沿用已有稳定 API、产物合同和验证状态；PanoToVR 为已有运行时的打包迁入。既有 tag 保持不变。

已知依赖告警：Argus 生产依赖审计报告一项已有的 `fast-uri` 中危漏洞（[GHSA-hrr3-gc8f-f4qj](https://github.com/advisories/GHSA-hrr3-gc8f-f4qj)）。未超过配置的 high/critical 发布阻断阈值；本次打包发布不扩大到依赖修复。
