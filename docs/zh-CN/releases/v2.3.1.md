# v2.3.1 — fast-uri 安全修复

## 简体中文

- 将 Argus 通过 Ajv 引入的间接依赖 `fast-uri` 从 **3.1.7 更新至 3.1.9**，修复中危告警 [GHSA-hrr3-gc8f-f4qj](https://github.com/advisories/GHSA-hrr3-gc8f-f4qj)。
- 修复后的锁文件已同步到 Argus 规范源码、生成的 Claude 插件和仅含 Argus 的 Arkclaw 包。直接依赖声明和公开运行时合同不变。
- 继续提供 **Argus**、**PanoToVR** 和 **Blender 重建**，同步版本号及固定版本安装说明。专用 Codex 安装器与 `argus.zip` 仍仅包含 Argus。

安装修复后的 Argus skill 到 Codex：

```sh
npx skills add realsee-developer/skills@v2.3.1 --skill argus --agent codex
```

安装 PanoToVR 或 Blender 重建时，选择 `--skill panotovr` 或 `--skill realsee-blender-reconstruction`。按安装后 skill 的说明配置依赖；运行时 skill 须通过其附带的锁文件安装依赖。

验证包括 stable 发布门禁、117 项 skill 测试、20 项仓库测试、分发同步、含 PanoToVR 离线帮助的全新安装烟测，以及报告 **0 个漏洞**的 Argus 生产依赖审计。不宣称新增远程处理或 Blender 重建验证。既有 tag 和 v2.3.0 发布说明保持不变。
