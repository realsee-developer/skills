# v2.4.0 — Argus 本地工具与 WorkBuddy 工作流

[English](../../releases/v2.4.0.md) | [简体中文](v2.4.0.md)

Argus 安装包新增本地前置条件检查与离线交付报告。WorkBuddy 用户可以安装完整技能目录，执行重建到结果收集，并获得根据已保存结果生成的报告。Argus 远程 API 和产物合同保持不变。

## 更新内容

- `scripts/check-local.mjs` 可从任意工作目录检查 Node.js、npm、依赖和配置是否齐全。依赖未安装时也可运行，不读取凭据文件内容或显示凭据值，也不访问网络。
- `scripts/inspect-result.mjs` 离线复用正式校验器。`--write-report` 保存 `verification.json`，分别记录本地、远程和算法状态，以及警告、缺失 ID 和产物信息。二进制检查覆盖文件头，不完整解码 GLB/EXR；视觉质量仍未评估。
- Skill 指令区分完整运行、只启动和单次查询，将输入警告保留到最终结果，并在中断后复用已保存的工作区。提交结果未知时不得自动重提。
- 双语 [WorkBuddy 安装指南](../workbuddy.md)说明完整目录、依赖配置、备份与技能发现。依赖安装兼容符号链接形式的 Skill 目录。Claude 和仅支持 CN 的 Arkclaw 分发包含新工具，并同步安装烟测。

## 安装

```bash
npx skills add realsee-developer/skills@v2.4.0 --skill argus --agent codex
```

三项 skill 继续提供。其他能力选择 `--skill panotovr` 或 `--skill realsee-blender-reconstruction`。按已安装 Skill 配置依赖，并参考[宿主安装指南](../install-guides.md)。专用 Codex 安装器与 Arkclaw `argus.zip` 仍仅包含 Argus。

## 验证范围

本地验证包括 19 项仓库测试、135 项 Argus 测试、发布门禁、分发同步与烟测，以及报告 0 个漏洞的 Argus 生产依赖审计。

在 WorkBuddy 5.9.2 中使用全部 12 张 CN 官方示例，完整完成了提交、状态查询、结果收集和离线复核，无缺失 ID 和警告。结果包含 2,963,520 个彩色点、12 张 840×420 EXR 深度图和 12 份相机位姿；未返回可选内参。该验证确认工作流与产物合同，不代表几何精度或视觉完整性已达标。

Global 沿用既有稳定验证记录。本次不宣称新增 Global、PanoToVR 或 Blender 真实运行验证。既有 tag 与历史发布说明保持不变；`v1.0.2` 继续作为冻结的旧版本线。
