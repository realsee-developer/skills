# v2.3.0 — PanoToVR

## English

- Adds **PanoToVR** (`panotovr`) to create a Realsee VR space from local panoramas and retrieve its VR URL. Supports automatic or supplied manifests and resuming polling with a known task code.
- Includes the runtime, locked dependencies, bilingual guides, a synthetic manifest template, a sanitized API contract, discovery links, and the generated Claude plugin.
- Packages **Argus**, **PanoToVR**, and **Blender reconstruction** together. The dedicated Codex installer and `argus.zip` remain Argus-only.

Install PanoToVR in Codex:

```sh
npx skills add realsee-developer/skills@v2.3.0 --skill panotovr --agent codex
```

PanoToVR requires Node.js 22+, npm 10+, regional app credentials, panorama-to-VR API access, and explicit upload authorization. Install its runtime dependencies in the installed skill directory using its SKILL.md.

Validation covers repository contracts, distribution sync, fresh-install smoke, runtime syntax/help, and release gates. No new remote processing or Blender reconstruction is claimed. Argus retains its existing stable API, artifact contract, and verification status; PanoToVR is a packaged migration of the existing runtime. Existing tags are unchanged.
