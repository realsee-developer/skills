# v2.4.0 — Argus local tools and WorkBuddy workflow

[English](v2.4.0.md) | [简体中文](../zh-CN/releases/v2.4.0.md)

Argus now includes local prerequisite checks and offline delivery reports in the installed skill. WorkBuddy users can install the complete skill directory, run a full reconstruction through collection, and receive a report generated from the saved result. The Argus remote API and artifact contract remain unchanged.

## Changes

- `scripts/check-local.mjs` checks Node.js, npm, dependencies, and configuration presence from any working directory. It works before dependencies are installed, does not read credential-file contents or display credential values, and does not access the network.
- `scripts/inspect-result.mjs` reuses the canonical validator offline. `--write-report` saves `verification.json` with separate local, remote, and algorithm statuses, warnings, missing IDs, and artifact details. Binary checks cover headers rather than full GLB/EXR decoding; visual quality remains unassessed.
- Skill instructions distinguish full runs from start-only and single-status requests, preserve input warnings in the final result, and reuse the saved workspace after interruption. Unknown submissions must not be retried automatically.
- Bilingual [WorkBuddy installation guidance](../workbuddy.md) covers the complete directory, dependency setup, backups, and skill discovery. Dependency setup supports symlinked skill directories. Claude and CN-only Arkclaw distributions include the new tools, with matching installation smoke coverage.

## Install

```bash
npx skills add realsee-developer/skills@v2.4.0 --skill argus --agent codex
```

All three skills remain available. Select `--skill panotovr` or `--skill realsee-blender-reconstruction` for the other capabilities. Follow the installed skill's dependency instructions and the [host installation guide](../install-guides.md). The dedicated Codex installer and Arkclaw `argus.zip` remain Argus-only.

## Validation scope

Local validation includes 19 repository tests, 135 Argus tests, release-gate checks, distribution synchronization and smoke checks, and an Argus production dependency audit with zero vulnerabilities.

A complete run in WorkBuddy 5.9.2 used all 12 CN official examples. Submission, status queries, collection, and offline inspection completed successfully, with no missing IDs or warnings. The result contained 2,963,520 colored points, 12 EXR depth maps at 840×420, and 12 camera poses; optional intrinsics were not returned. This confirms the workflow and artifact contract, not geometric accuracy or visual completeness.

Global's existing stable verification is carried forward. This release does not claim a new Global, PanoToVR, or Blender live verification. Existing tags and historical release notes remain unchanged; `v1.0.2` remains the frozen legacy line.
