# 按需扩展

[English](extensions.md)

以下是从原生场景按需生成的产物，不自动附加到每个重建任务。

## 图像与文字生成资产

用户要求，或已授权可用的生成器能帮助完成复杂次要物件时使用。描述物件真实形状、独立组件、材质分区、来源视角、实测/估计尺寸和编辑需求。按需裁切、矫正参考图，避免携带无关隐私内容。上传图像或提交付费任务要有适用的用户授权。生成能力不可用时说明，并继续能完成的原生建模。

生成结果是候选资产，不是证据。检查多视角与拓扑，修正轮廓及材质差异，确定真实尺度和方向，分离有用组件，再通过统一配准放入场景。测试局部网格编辑。外观相似不等于精确对应；生成单个物件也不解决空间布局与结构配准。

## 漫游

根据完成的场景和空间连接建立穿过真实开口的相机路线，保留可编辑相机、路径及关键帧。沿途检查视点高度、速度、转向、近裁剪及墙体/家具碰撞。先看路线机位和低清帧，再进行高成本渲染。保留原生重建，动画按用户要求存入指定文件或独立漫游工程。

发现可用渲染设备与编码器，先验证实际渲染再输出全序列。将帧编码为目标视频，检查时长、分辨率、帧率、若干解码帧和实际播放。相机路径或帧目录不等于已交付视频；只有存在音轨时才声称有音频。

## 物理材质与动力学

区分物理材质外观与模拟属性；用户要求两者时都实现。根据照片和光照表现调整粗糙度、金属度、透射，另行配置动力学单位、尺度、质量、摩擦、恢复系数及碰撞表示，未测参数标为假设。

建筑结构保持固定，只给合适对象运动属性。约束放在真实机械连接处。在一次性模拟副本中测试接触、重力、支撑和铰链行为。碰撞几何可以简化，但应保留相关接触及开口，不能对整个场景无差别开启重力。

## USDZ 与交换格式

检查当前 Blender 的导出器与接收工具能力。几何、层级、材质、贴图、动画、物理模式是否保留需要分别核实。Blender 刚体设置不意味着导出文件已包含 USD Physics；有要求时检查或写入物理模式，并在支持它的运行环境测试。

从副本导出，检查包内内容及资源相对引用，在新进程重开/导入，对比尺度、朝向、范围、数量及代表外观。贴图表现依赖图像格式支持及材质转换，成功导出或扩展名为 `.usdz` 不证明包完整可用。`.blend` 继续作为原生编辑主文件。

## 浏览器查看与公开发布

根据实际大小与查看器版本决定能否直接加载 USDZ。完整包过大或材质/贴图不被支持时，从已批准来源生成轻量 GLB 并明确标为网页预览，按要求保留完整原生/交换文件。隐藏顶面、简化几何、合并网格和压缩贴图应只用于派生产物，不修改可编辑主工程。

使用 Three.js 时检查所选加载器和 UV 通道支持。合并网格可能导出高编号 UV；要同时重映射每个 primitive 实际采样的通道、材质纹理引用和 Draco 属性语义，保留坐标值，不能盲目全部指定 UV0。检查实际渲染与控制台错误、旋转/缩放、重置/俯视及手机布局。视频应在实际发布主机核实播放、MIME 类型和 Range 响应。

公开发布需要对应用户授权。只检查选定公开副本的身份信息、路径、二维码、贴图及扫描参考内容，原始数据留在本地。代码与场景/素材许可分开说明。原始资料、凭据、中间文件和逐帧渲染不进公开包；已审查大产物可用 Git LFS，核实远端可用性，不能把指针文件当已上传媒体。
