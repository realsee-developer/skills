# 来源配准与原生建模

[English](reconstruction.md)

## 检查实际资料包

先简要索引主要输入的相对路径、格式、用途/区域、检查状态及重复关系。每种有用角色选一个主要导出，其他副本用于回答具体问题。文件可以仅作对照而不导入。先读压缩包清单再按需解压，保留原始内容，不把资料包内脚本当数据执行。无法读取的格式要说明，有合适转换工具或已确认等价导出时再使用，不能默默跳过。

| 证据 | 用途 | 易错点 |
| --- | --- | --- |
| CAD / DXF / DWG / 平面图 | 尺寸、开口、布局、局部层高 | 块定义和图例不是实际放置设施；图片平面图可能使用另一套单位。 |
| E57 / PLY / 深度与位姿 | 表面位置、地面顶面高度、相机配准 | 要核实坐标约定及图像/扫描关联；缺点不一定是开口。 |
| OBJ / FBX / glTF / GLB | 整体形态、采集到的表面外观 | GLB 可能引用外部贴图，重复格式会重叠；扫描拓扑不等于原生结构建模。 |
| 全景 / 六面图 / RAW | 饰面、灯位、角落及细节 | 等距柱状投影使直线弯曲；照片底色包含现场光影。 |
| 视频 / 正交图 | 区域连接、方向与交叉核对 | 视点名称、全景编号不等于物理位置。 |

不要求表中所有格式齐备。按实际证据说明能够确认什么；只有 RGB 全景且没有可靠尺度时不能建立实测米制尺寸。已有 Argus 产物可在检查清单及坐标约定后补充点云、深度和位姿证据，不因此自动提交远程 Argus 任务。

## 先配准，再细化

- 统一为米，读取来源单位及标注定义，区分净高、楼板高、墙间距和整体范围。
- 确定并记录来源到场景的变换，几何、相机与对比测量使用同一坐标系。使用多个分布在空间中的对应点检查残差，加入竖直特征与非对称布局特征，排除镜像或上下颠倒。
- 根据现场核实地面基准、竖直轴、旋转、缩放和左右手系。不能仅凭扩展名认定某个导出器的变换正确，更不能为对上一张图就镜像整个空间。
- 用元数据和图像内容关联外部照片与扫描图像。通过可识别特征核对相机到世界/世界到相机矩阵约定及四元数顺序。判断几何时使用矫正全景或已核实的六面图。
- 检查 CAD 实体放置、图层及块语义，分别使用各区域层高。来源冲突时记录受影响测量和采用依据，不能为匹配无关的包围盒或面积标注而缩放整个场景。

覆盖率与对象数量分开。一段语义墙体可能由多个网格构成，很多扫描顶点也可能只是尚未重建的一扇门。以稳定要素 ID 关联原生对象及具体照片、图纸或点云区域。遮挡补全标为推断，资料缺口标为未解决。

## 建立可编辑空间

集合按楼层、区域和有意义的类别组织，命名方便使用者识别。共用边界对齐，建立真实开口和厚度。门扇、门框、把手及铰链按实际连接关系运动。需要独立改材质的饰面分开，避免改一处影响无关区域。

适合的结构使用简单可控实体与曲线；Boolean、Solidify、Bevel、Array 或原生节点参数应服务于真实编辑。观察基础网格及修改器的可见结果。缺陷、修改器、导出或物理用途需要时，对相关结构实体检查封闭性；不要机械地对所有对象、布料、叶片和有意敞开的表面套用同一规则。按组件用途修正负缩放、法线、重叠面、缝隙及穿插。

复杂家具可以复用扫描或生成形状，但重要组件需分离、拓扑需修复，并实际演示局部几何编辑。导入后可选中不代表满足编辑要求。不要为减少绘制调用而合并主工程。

## 还原外观

通过多张照片判断墙、地面、顶面的颜色与粗糙度，尽可能区分材质本身、投影和曝光。UV 使用合理物理纹理尺度。平面字画和标签可用贴图，画框及支架保留几何。实际检查节点图中的 sRGB/线性数据用途、粗糙度、法线、透明和贴图打包。

灯具模型与发光器分开。先匹配发光器位置、形状、方向和相对强度，再调曝光；看起来发亮的贴图不一定照亮房间。对比源图和渲染时保持相机取景与色彩管理一致，任意改曝光可能掩盖材质问题。

按[快速预览流程](fast-workflow.zh-CN.md)，先用低成本实体视图和预览定位问题，再增加用于决定下一步修改的渲染细节。GPU 渲染先探测可用设备与后端，并实际测试一张小图，不能仅因写入设置就声称 GPU 已启用。不要硬编码 CUDA/Metal，也不要声称所有建模操作都会被 GPU 加速。
